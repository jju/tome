# Lucky Strike Inn

The only inn in the village of [DennelCrossing](DennelCrossing.md). Run by a [Halfling](Halfling.md) named [Joyas Waterskin](JoyasWaterskin.md), and has an [Aarakocra](Aarakocra.md) barkeep named [Agla](Agla.md). 

In [Iall IC4996](IC4996.md) the inn was host to a whole crowd of people sick with the [wasting chills](Sereno.md).
